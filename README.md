# 🎓 Crud20_10_2026 – ASP.NET MVC CRUD Project

**Developed by Ankit Pandey**

A simple CRUD application built using **ASP.NET MVC, C#, and SQL Server** to manage database records efficiently.

## ✨ Features
- Create new records
- View records
- Update existing records
- Delete records
- SQL Server database connectivity

## 🛠️ Technologies Used
- C#
- ASP.NET MVC
- ADO.NET
- SQL Server
- HTML, CSS, Bootstrap

## ⚙️ How to Run
1. Clone the repository.
   ```bash
   git clone https://github.com/Ankitpandeyup51/Crud20_10_2026.git
   ```
2. Open the project in Visual Studio.
3. Configure the SQL Server connection string in `Web.config`.
4. Create the required database and table.
5. Run the application.
